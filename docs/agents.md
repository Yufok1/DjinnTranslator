# 🧠 Agent Behavior Documentation

Each agent operates within its sovereign domain while maintaining harmony with the greater system. This document defines their capabilities, triggers, and interactions.

## Inter-Agent Coordination

### Primary Interactions

1. **Cursor ↔ Djinn**
   - Cursor requests pattern optimization
   - Djinn suggests flow improvements
   - Cursor implements approved changes
   - Djinn verifies pattern integrity

2. **Djinn ↔ Arbiter**
   - Djinn proposes pattern evolution
   - Arbiter validates against rules
   - Djinn adjusts based on feedback
   - Arbiter monitors compliance

3. **Arbiter ↔ Olive Branch**
   - Arbiter detects violations
   - Olive Branch initiates recovery
   - Arbiter enforces corrections
   - Olive Branch restores harmony

4. **Olive Branch ↔ Cursor**
   - Olive Branch detects structure issues
   - Cursor performs refactoring
   - Olive Branch verifies harmony
   - Cursor maintains stability

### Override Hierarchy

1. **Critical Overrides**
   - Arbiter can override all agents
   - Olive Branch can override for harmony
   - Cursor can override for structure
   - Djinn can override for flow

2. **Delegation Rules**
   - Structure issues → Cursor
   - Flow issues → Djinn
   - Rule issues → Arbiter
   - Harmony issues → Olive Branch

## Activation Protocols

### Normal Operation
1. Agent detects trigger
2. Assesses severity
3. Takes appropriate action
4. Reports to relevant agents
5. Maintains system harmony

### Override Operation

4. System stabilizes
